# Repository cleanup 2026-09-29

The cleanup of branch `agent/repo-cleanup` followed the
[restructure plan](repo-restructure-plan.md) (phases 1-7) and the user's
instruction "do the cleanup and remove denial". It removed 1,901 files and
moved or rewrote the documents, leaving 1,885 tracked files, down from 3,758.
Git history is unchanged, and nothing was pushed.

## Restoring a file

Every removed path is listed with its family in
[archived-files.tsv](archived-files.tsv). The local annotated tag
`archive/pre-cleanup-2026-09-29` points at the last commit before the cleanup
(`21f87a23`). It is local only and must never be pushed, because it points at
unfiltered history.

```sh
git checkout archive/pre-cleanup-2026-09-29 -- <path>        # one file back into the tree
git show archive/pre-cleanup-2026-09-29:<path>                 # read it without restoring
git worktree add --detach /tmp/old archive/pre-cleanup-2026-09-29   # the old tree, runnable in place
```

Archived scripts address each other by their repository paths, so run them
from a detached worktree of the tag rather than copying them back one by one.
Each family commit on the branch can also be reverted on its own with
`git revert <sha>`.

## Other changes

- **Tests.**
  - `configs/repository-tests.json` is the only tier list. The runner reads
    it, and `--list TIER` prints a tier. At the base commit, the shell
    arrays had drifted from the registry, so every tier failed before its
    first suite.
  - `scripts/host/check-repository-static.py` runs all the static checks in
    one command, and every tier runs it.
  - `test-rog5-perf-mode.sh` is registered.
  - The 7.1.4 patch tests now read the 7.2.7 copies of the same patches.
    Their fixtures were refreshed or verified against pristine v7.2.7.
  - Three live tests no longer load the headless controllers.
- **Kernel builder.**
  - The builder defaults to the 7.2.7 policy and series.
  - The diagnostics checker's command-line default is now the 7.2.7 warning
    policy.
  - A prepare-only build produces the same series binding and config hash as
    before the cleanup. The only changed recorded inputs are those two
    scripts.
- **CI.**
  - The Android boot tools come from a cache or are fetched with retries.
    They are verified against their pinned hashes in both cases.
  - The board and panel jobs build on v7.2.7.
  - The network-root QEMU job and the power-usb publication job are removed.
- **Status.**
  - `docs/status/components.json` is the only status source. It now includes
    the installed default and fallback bundles.
  - `scripts/host/render-current-state.py` generates the short
    `docs/current-state.md`.
  - The July-September log is in
    [current-state-log-2026-07-to-09.md](current-state-log-2026-07-to-09.md).
- **Docs.**
  - Stale documents moved to `docs/history`, and `docs/archive` moved to
    `docs/history/archive`. Hardware notes are in `docs/hardware`.
  - `development.md` keeps only the tools in use. Its previous version is
    [development-log-2026-07-to-09.md](development-log-2026-07-to-09.md).
  - `README.md`, `ROADMAP.md` and `CLAUDE.md` describe the phone as it is
    now.
  - `test-results/README.md` is a generated index of the results by month.

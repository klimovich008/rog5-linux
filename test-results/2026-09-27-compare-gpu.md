## 2. Details, top items

**IFPC (1).** Stock keeps the GPU "on" between submits and lets the GMU collapse GX/SPTPRAC after its hysteresis (`A6XX_GMU_PWR_COL_INTER_FRAME_HYST/SPTPRAC_HYST = 0x000a1680`, `IFPC_ENABLE_MASK`/`SPTP_ENABLE_MASK`, `adreno_a6xx_gmu.c:380-395`); the CP restores the listed registers on wake (`CP_INIT_REGISTER_INIT_LIST_WITH_SPINLOCK`, `adreno_a6xx.c:983`, list patched at `:878-881`). Ours: `a6xx_gmu_power_config` (`a6xx_gmu.c:800-845`) only writes `0x9c40400` and skips the IFPC/SPTP cases because `idle_level == ACTIVE`, so GX stays powered until runtime suspend 66 ms after the last job (`DRM_MSM_INACTIVE_PERIOD`, `msm_gpu.h:235`); a compositor at 60 fps submits every 16 ms → never collapses while the screen animates. Mainline added IFPC for a7xx only (register list with apertures, `a6xx_gpu.c:803-870`; quirk at `a6xx_catalog.c:1547-1557`), plus IFPC-aware `a6xx_progress` (`:2408-2414`) and perfcounter/sysprof OOB (`a6xx_gmu.c:2084-2110`, `msm_perfcntr.c:261-299`). What is missing for a660 is the a6xx-style CP init and the two stock register lists (stock `a6xx_ifpc_pwrup_reglist` `:56-93` = CP_CHICKEN_DBG, CP_DBG_ECO_CNTL, CP_PROTECT_CNTL, CP_PROTECT_REG+0..31, CP_AHB_CNTL; `a650_ifpc_pwrup_reglist` `:96-113` = CP_PROTECT_REG+32..47; `a6xx_pwrup_reglist` `:23-53` addr-mode/UCHE/NC_MODE/PC_DBG_ECO/GBIF_GX_CONFIG; `a650_pwrup_reglist` `:116-124` TPL1 bicubic tables, UCHE_CMDQ_CONFIG). Since the a660 SQE (`a660_sqe.fw`) is the stock one, the list format is the same. Test plan when implemented: 300-cycle wake test + `RBBM_PERFCTR_GMU` IFPC counter (`a6xx_gpu.c:1329`) + screen-on idle current.

**ACD (2).** Stock a660 (0x06060001 = `adreno_gpu_core_a660v2`, `gpulist.h:1653-1659`) enables ACD with the bin-0 levels; kgsl builds the same `hfi_acd_table_cmd` (version 1, stride 1, `enable_by_level` bit per level from the lowest, `adreno_a6xx_gmu.c:2445-2480`) as mainline (`a6xx_gmu.c:1995-2023`, struct `a6xx_hfi.h:159-166`), and sends the same QMP string. Our booted DT has `aoss_qmp` (`power-management@c300000`, phandle 0x50) but the GMU node lacks `qcom,qmp`, so `a6xx_gmu_acd_probe` returns with `enable_by_level = 0` and the GMU runs at the full voltage margin. One caveat beyond the message order above: the mainline path also sends `gx_votes[].acd = 0xffffffff` in the perf table (`a6xx_hfi.c:344`), same as stock (`adreno_a6xx_rpmh.c:334`), so only the ACD feature path itself is untested with the linux-firmware `a660_gmu.bin` (the stock v3.1.5 fw is unusable with mainline per `docs/development-lessons.md:4187`).

**DDR (3).** Our `a6xx_gmu_set_freq` (`a6xx_gmu.c:155-230`) sends `bw_index 0` and then `dev_pm_opp_set_opp` (CPU icc vote, peak only, avg 0 — stock's `bus_percent_ab` is also 0 by default, `kgsl_bus.c:103-113`, so no AB delta). The loss vs stock is only gpubw_mon's dynamic min/max window (e.g. at 443-608 MHz stock can vote down to 768/1017 MHz DDR or up to 3196 MHz; we sit at 1555). No mainline hook computes GPU bus busy (`ram_time/ram_wait` come from GMU perfcounters in kgsl).

## 3. Works the same / not needed (checked)

- OPP table = stock bin 0 (10 levels, corners identical); bins 5/7 in stock equal bin 0; bins 1/3 add a 900 MHz level without a corner (unused) → no speed-bin filtering needed. GMU vote = 200 MHz at MIN_SVS both (`adreno_a6xx_rpmh.c:268`, gmu opp-level 0x30).
- HWCG list: 49 entries, identical (diffed normalized `a660_hwcg` vs `a660_hwcg_regs`). GBIF QSB 0x00071620 + client QoS 0x3, hang-detect `0xcfffff` (`a6xx_gpu.c:1343` vs `gpulist.h:1644`), `PC_DBG_ECO_CNTL` 0x00300200 = stock 0x00300000|tseskip bit 9, `pdc_in_aop`, FAL10 veto writes, UBWC HBB 16/MAL 32/mode 4: same.
- LLCC: GPU slice 12 / GPUHTW 11, 1024 KB, prio 1, retain_on_pc — identical (`llcc-lahaina.c:60-61` vs `llcc-qcom.c` sm8350); `a6xx_llc_activate` programs `GBIF_SCACHE_CNTL0/1` like stock's MMU-500 path.
- Nap: stock `qcom,no-nap` disables it (`lahaina-gpu.dtsi:48`, `kgsl_pwrctrl.c:1541`) → nothing to add. LM: not in the a660 feature set (stock too). Preemption/content protection/L3 votes (userspace-driven context constraints)/gpu-mempools/qdss: kgsl-only, not needed. `qcom,tzone-names`: kgsl telemetry only.
- Idle timing: stock slumber after 80 ms (`CONFIG_QCOM_KGSL_IDLE_TIMEOUT`), ours runtime suspend after 66 ms: equivalent, except item 1.
- Governor: stock msm-adreno-tz (TZ-side DCVS, `governor_msm_adreno_tz.c`) vs simple_ondemand 50/10 %, 50 ms + msm boost/idle logic: different algorithm, but the earlier trace shows 840 MHz reached and 85 % residency at 315 MHz, so no functional gap; `gpu_clamp_to_idle` stays off for a660 (`a6xx_gpu.c:2757-2758`), as upstream intends.
- Thermal cooling device registers (`#cooling-cells`, `of_devfreq_cooling_register`) and both gpu zones have cooling maps.
- Patches 0012 (propagate pwrlevel probe error) and 0040 (defer until IOMMU attached) are benign hardening; ASUS overlays (`ZS673KS-*-overlay.dts`) contain no GPU changes (only the empty "overlay for lahaina-gpu.dtsi" comment blocks).
